# Lab 01: Single-Area OSPF

**Purpose:** Configure a single-area OSPF network connecting multiple routers and computers.

**Background:** Refresh OSPF configuration knowledge and routing principles.

**Key Outcomes:**
- Built a working single-area OSPF network from scratch with 7 networks, 4 routers, and 4 computers
- Configured router interfaces, subnets, and IP addresses independently
- Diagnosed and resolved connectivity and routing issues
- Learned to anticipate common configuration mistakes and apply solutions efficiently
- Create a reference topology and configuration for future labs
- Documented process and troubleshooting steps
