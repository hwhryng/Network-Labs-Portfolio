# Lab 03: Advanced OSPF Areas (Stubby, Totally Stubby, NSSA)

**Purpose:**  
Set up OSPF stub areas, totally stubby areas, and NSSAs, and connect multi-area OSPF to an EIGRP area to learn about larger network topologies.

**Background:**  
Focused on configuring complex OSPF areas, preparing topologies for clarity, and understanding area restrictions and purposes.

**Key Outcomes:**  
- Configured 9 routers across multiple OSPF areas and connected to an EIGRP area  
- Practiced labeling and organizing complex topologies  
- Learned area-specific OSPF rules and configurations  
- Built confidence in self-directed learning for network setup  
- Improved ability to plan and execute larger-scale network designs
