# Lab 05: BGP (IPv6)

**Purpose:**  
Configure iBGP and eBGP in IPv6, connecting multiple routing domains using GNS3, to practice advanced BGP concepts and troubleshooting.

**Background:**  
Focused on using GNS3 as a simulation tool and understanding IPv6 BGP routing behavior.

**Key Outcomes:**  
- Configured BGP in IPv6 across multiple routers and routing domains  
- Improved attention to detail in command entry and troubleshooting  
- Strengthened problem-solving and research skills  
- Learned to use GNS3 effectively for complex network simulations  
- Gained confidence in handling multi-domain IPv6 networks
